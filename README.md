# CareCircle

A family care coordination app for tasks, appointments, the care circle and a shared timeline.

## Getting started

```bash
npm install
npm run dev      # development server at http://localhost:3000
npm run build    # production build
npm start        # serve the production build
npm run lint     # run ESLint
```

## Current status

- Data is stored in each browser's localStorage only. Nothing is shared between devices or people.
- Care circle invitations are saved locally as pending and are not emailed.
- There is no sign-in yet.
